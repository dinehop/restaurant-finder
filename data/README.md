# Public reference data

This directory contains small, human-readable reference datasets maintained alongside the public DineHop documentation.

## Food-hygiene schemes

[`food-hygiene-schemes.json`](food-hygiene-schemes.json) describes the official food-hygiene and inspection schemes currently supported by DineHop.

The file records:

- Country and jurisdiction coverage.
- Official scheme and authority names.
- The result format used by each authority.
- A direct link to the relevant official service or dataset.

This is a coverage reference, not a copy of the authorities' inspection records and not a DineHop API. Consult the linked authority for the latest record about a specific establishment.
