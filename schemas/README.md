# Illustrative schemas

[`hop.example.schema.json`](hop.example.schema.json) is a small JSON Schema showing how a named, ordered restaurant outing could be represented as structured data.

The accompanying [`hop.json`](examples/hop.json) uses fictional venues and validates against the schema.

## Important boundary

This schema is an independent documentation example. It is not a DineHop API, import format, export format or compatibility commitment. Applications should not depend on it for integration with the DineHop product.
