# Security policy

## Reporting a vulnerability

Please report a suspected security or privacy vulnerability privately to [contact@dinehop.app](mailto:contact@dinehop.app) with the subject line `[Security] DineHop report`.

Include, when available:

- The affected feature or page.
- The steps needed to reproduce the issue.
- The potential impact.
- Relevant device, operating-system and app-version information.
- A safe proof of concept that does not contain another person's data.

Do not include passwords, access tokens, API keys or unnecessary personal data. Do not use a public GitHub issue for a vulnerability report.

## Responsible testing

Please avoid actions that could disrupt the service, access another person's information, create excessive traffic or alter production data. Stop testing and contact DineHop if the investigation could affect other users.

## Disclosure

Allow DineHop a reasonable opportunity to investigate and address a report before publishing details. Receipt of a report does not create a bug-bounty agreement or guarantee payment.

## Repository scope

This public repository contains product information and media assets. It does not contain the application source code. Reports about inaccurate public documentation may be sent to the same contact address without the security subject line.
