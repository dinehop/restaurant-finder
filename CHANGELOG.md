# Public product updates

This file records public, user-visible DineHop updates. It is not an application source-code changelog.

## 1.4.0, 16 August 2026

- Added Hops for organising several venues into one named outing plan.
- Added been-there verdicts for places in a Hop.
- Made saved places searchable, filterable and sortable by distance.
- Added permanent Home, Hops and Profile navigation.
- Added filters for budgets in local currency and minimum ratings.
- Added live distance and direction information on place details.
- Corrected dietary filtering outside English-language searches.

This version is available on Android through Google Play. An iOS version is
under development, with no announced release date.

Future entries will be added after an update is publicly released. Internal plans, release candidates and unannounced features will not be listed here.
