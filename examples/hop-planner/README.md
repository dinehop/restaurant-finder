# Standalone Hop planner example

This small browser example demonstrates the idea behind a DineHop Hop: collect several places, arrange the stops and export a simple itinerary.

All venue names and details are fictional. The example was written independently for this public repository. It does not contain DineHop application source code, connect to DineHop services or reproduce the production interface.

## Run locally

Open [`index.html`](index.html) in a modern browser. No build step, package installation or network connection is required.

The example supports:

- Adding a fictional venue.
- Moving a stop earlier or later.
- Removing a stop.
- Exporting the plan as a Markdown file.

See the [illustrative Hop JSON schema](../../schemas/hop.example.schema.json) for a separate example of how the same concept can be described as structured data.
