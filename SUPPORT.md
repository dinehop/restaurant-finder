# DineHop support

## Product support

Email [contact@dinehop.app](mailto:contact@dinehop.app) for help with DineHop.

To make the request easier to investigate, include:

- The device model and Android version.
- The DineHop version shown in the app or Google Play.
- A short description of what happened and what you expected.
- The steps that reproduce the problem, if known.
- A screenshot with personal information removed, if it helps explain the issue.

Do not send passwords, verification codes, API keys, payment information or authentication tokens.

## Account deletion

Account deletion is available from the app. The public instructions are at [dinehop.app/delete-account](https://dinehop.app/delete-account).

## Security reports

Potential vulnerabilities should be reported privately by following [SECURITY.md](SECURITY.md). Do not publish sensitive security details in a GitHub issue.

## Repository scope

This repository contains public product information and media assets. It is not the mobile application source repository. GitHub Issues are not used for product support.
