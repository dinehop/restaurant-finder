# DineHop link snippets

These small snippets help articles, reviews, directories and technical references link to the correct DineHop website or Android listing.

## Standard Markdown link

```markdown
[DineHop Restaurant Finder](https://dinehop.app)
```

## Android download link

```markdown
[Download DineHop on Google Play](https://play.google.com/store/apps/details?id=restaurant.app)
```

## Short directory entry

```markdown
**[DineHop Restaurant Finder](https://dinehop.app):** Find restaurants by dish, cuisine or area, compare practical details and organise several places into a Hop.
```

## Linked logo in HTML

```html
<a href="https://dinehop.app" aria-label="Visit DineHop Restaurant Finder">
  <img
    src="https://raw.githubusercontent.com/dinehop/restaurant-finder/main/assets/brand/dinehop-logo.svg"
    alt="DineHop Restaurant Finder"
    width="180"
  >
</a>
```

## Text link in HTML

```html
<a href="https://dinehop.app">DineHop Restaurant Finder</a>
```

Use `DineHop` with the same capitalisation and do not imply an endorsement or partnership. See the [brand asset guidance](../docs/brand-assets.md) for logo and screenshot use.
